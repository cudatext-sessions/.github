# CudaText - A Text Editor for Files You Are Writing

![CudaText with one source file the user saved in a project folder](https://cudatext.github.io/img/cudatext-main.png)

## Product Snapshot

CudaText is a light editor for code and other text you are allowed to change. Lexers color a filetype. Sessions remember which files you had open. Several carets let you edit repeated spots in a file you understand. Plugins and macros are optional, and a macro is still a command.

Point it at a folder you can explain. Do not open files inside the Windows directory to try a tweak. Do not run a snippet you copied from a page you have not read. The editor will not stop a command from doing what it says.

## Mount and Burn Toolkit

| Task | What you get |
|---|---|
| Edit | The text of a file you may change |
| Lexer | Colors for a filetype you recognize |
| Session | The set of files you reopen tomorrow |
| Carets | Several cursors in one file you know |
| Macro | A command you wrote and can read |
| Project | A folder that is not a system path |

A session is a convenience. The backup is a copy of the folder. Closing the editor does not delete the files.

## Deep Dive

Create the file, save it with the right extension, and type a few lines you can check. If you bind a tool, read the command first. An error from that tool refers to the saved file. An unsaved buffer is a different text.

Plugins can add a lot of surface. Add one only when you know what it changes. A plugin that rewrites files on save is a bad first experiment. Keep a copy of anything you cannot replace. CudaText does not grant rights to a closed-source tree you were not given.

## Adoption Paths

CudaText fits a script, a config you own, or notes that happen to be code. It fits a small project better than a tour of every plugin. It does not fit a wish to patch a program you do not maintain, and it does not belong pointed at someone else's private files.

## Install Walkthrough

Prerequisites: A project folder of your own, and a compiler only if you intend to build.

1. Install CudaText and open the folder you chose.
2. Create a file, save it, and type a few lines.
3. Turn on the lexer that matches the extension.
4. Reopen the session and confirm the edit is on disk.
5. Add a tool command only after you have read it.
